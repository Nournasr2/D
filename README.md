# نشاط كلمات بحركة الفتحة
نسخة تفاعلية RTL جاهزة للرفع على GitHub Pages.

- ٣ كلمات: قَرَأَ — كَتَبَ — خَرَجَ
- توصيل حقيقي بالسحب والإفلات مع إمكانية تغيير التوصيل.
- ٣ صور اختيار: زَارَ — رَكَعَ — أَكَلَ.
- لا توجد درجة أو صح/خطأ أو ألوان تقييم.
- بعد الإكمال يكتب الطالب رقم واتساب، ثم يُجهَّز ملف PNG واحد يحتوي على **الكلمات + الصور التي تم توصيلها + الصور التي اختارها الطالب + اختياراته**.
- تظهر معاينة للصورة داخل نافذة الإرسال، مع زر حفظ ومشاركة للمتصفحات التي تدعم مشاركة الملفات.
- يفتح الموقع محادثة واتساب للرقم المدخل، والطالب يرسل الصورة بنفسه.

> الصور الأساسية في النشاط تُحمّل من روابط Pexels، لذلك يلزم اتصال بالإنترنت لظهورها.
